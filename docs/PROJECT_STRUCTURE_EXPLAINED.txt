Hello! Welcome to the Election Campaign Analysis project.

If you are a beginner looking at this folder for the first time, this document is written specially for you in simple, plain English. It explains what this project is, how it works, what every single folder does, and what every file inside each folder contains.

--------------------------------------------------------------------------------
1. WHAT IS THIS PROJECT ALL ABOUT?
--------------------------------------------------------------------------------
This project analyzes 20 years of Indian Lok Sabha General Election results (from the years 2004, 2009, 2014, 2019, and 2024). 

It takes messy raw election numbers from the Election Commission of India (ECI), cleans them up, fixes party names, calculates interesting metrics (like seat volatility, alliance seats, and winning margins), makes high-resolution charts, and presents everything inside an interactive website (a Streamlit dashboard) where you can filter data by year, state, alliance, or party.

3. EXPLANATION OF EVERY FILE & FOLDER IN DETAIL
--------------------------------------------------------------------------------

----------------------------------------
ROOT FOLDER FILES
----------------------------------------
1. PROJECT_STRUCTURE_EXPLAINED.txt (This file)
   - Written in simple English so anyone can understand every piece of the codebase.

2. README.md
   - The main documentation file for GitHub. It explains the project overview, objectives, installation instructions, color rules, and how to run the project.

3. PROJECT_REPORT.md
   - A deep, technical data science report. It explains the math, data cleaning steps, chart rationale, and political insights in depth.

----------------------------------------
1. THE `app/` FOLDER (Streamlit Web Application)
----------------------------------------
This folder contains all the code for the interactive web dashboard.

- main.py:
  The entry point of the website. When you run `streamlit run app/main.py`, this file creates the homepage, displays summary metric boxes, and sets up the layout.

- utils.py:
  The brain of the website. It contains code that loads datasets into memory, creates the sidebar filters (Year, State, Alliance, Party, Seat Type), and automatically calculates dynamic text insights based on what filters you pick.

- pages/1_Overview.py:
  Page 1 of the website. Shows national coalition seat trends and vote-to-seat conversion graphs.

- pages/2_Party_Analysis.py:
  Page 2 of the website. Displays party seat counts, total votes, postal vote dependence (%), seat retention vs loss, and vote conversion efficiency.

- pages/3_State_Analysis.py:
  Page 3 of the website. Shows battleground state volatility rankings and victory margin boxplots.

- pages/4_Constituency_Analysis.py:
  Page 4 of the website. Shows top turnout seats, winning margin distributions, reserved seat breakdowns, extreme wins, and a searchable candidate/constituency table.

- pages/5_Insights.py:
  Page 5 of the website. Summarizes key strategic election takeaways, data limitations, and future machine learning plans.

----------------------------------------
2. THE `data/` FOLDER (Election Data Files)
----------------------------------------
This folder holds all raw data from the Election Commission of India and cleaned datasets generated by Python scripts.

- data/raw/constituency.csv:
  Raw CSV containing winning and runner-up candidate results for all 543 constituencies from 2004 to 2024.

- data/raw/election_results_2024.csv:
  Detailed raw results for the 2024 Lok Sabha elections, including EVM votes, postal votes, and total candidate votes.

- data/raw/result_by_party_cleaned.csv:
  Raw national party summary data showing votes and seats won per party per year.

- data/raw/result_by_state_cleaned.csv:
  Raw state-level party summary data showing votes and seats won per state per year.

- data/processed/constituency_master.csv:
  Cleaned version of constituency data with standardized party and state names.

- data/processed/party_summary_master.csv:
  Cleaned party summary data with combined split records.

- data/processed/state_summary_master.csv:
  Cleaned state summary data with validated seat tallies.

- data/processed/constituency_engineered.csv:
  Final constituency dataset enriched with calculated columns like Coalition Block (NDA/UPA), Seat Flip Status (1 if flipped, 0 if retained), and Margin Percentage.

- data/processed/party_summary_engineered.csv:
  Final party dataset with calculated Seat Conversion Efficiency metrics.

- data/processed/state_summary_engineered.csv:
  Final state dataset with calculated State Volatility Rates (%).

- data/processed/data_quality_report.md:
  A generated text report detailing how many rows were cleaned and verified.

5. THE `src/` FOLDER (Core Python Source Code)
----------------------------------------
This folder contains all Python modules that process data and build charts.

- src/__init__.py:
  Tells Python that `src` is a package so modules can import from each other.

- src/data_loader.py:
  Contains code to load raw CSV files from disk safely with error checking.

- src/cleaner.py:
  Contains code to clean raw data, standardize party acronyms (e.g. `BJP`, `INC`, `SP`), fix state names (`Orissa` -> `Odisha`), handle Surat 2024 uncontested seat edge case, and recalculate missing vote percentages.

- src/feature_engineering.py:
  Adds new analytical columns: matches historical elections to track seat flips, calculates State Volatility Rates, groups parties into Coalition Blocks (NDA, UPA/I.N.D.I.A., Left Front), and computes FPTP Seat Conversion Efficiency.

- src/eda_utils.py:
  Contains aggregation helper functions used during data analysis.

- src/visualization.py:
  A facade file that re-exports all plotting routines so legacy code can run without import errors.

- src/visualizations/ (Submodules for drawing charts):
  - __init__.py: Package exporter.
  - base.py        : Global chart styles, 300 DPI save helper, chart footer helper, official party hex colors (BJP Saffron `#FF9933`, INC Blue `#19A0FF`, etc.), and dataset column detectors.
  - party.py       : Functions to draw party-wise charts (`seats_by_party`, `votes_by_party`, `postal_vote_share`, `vote_seat_conversion`, `party_retention_loss`).
  - state.py       : Functions to draw state-level charts (`state_volatility_ranking`, `state_margin_distribution`).
  - constituency.py: Functions to draw constituency charts (`turnout_top20`, `reserved_category_wins`, `extreme_margins`).
  - statistical.py : Functions to draw macro & statistical charts (`coalition_trajectory`, `margins_hist`, `evm_vs_postal_scatter`).

--------------------------------------------------------------------------------
4. HOW ALL PIECES FIT TOGETHER (THE WORKFLOW)
--------------------------------------------------------------------------------
1. `src/data_loader.py` reads raw CSV files from `data/raw/`.
2. `src/cleaner.py` cleans missing values and standardizes party/state names, producing `data/processed/*_master.csv`.
3. `src/feature_engineering.py` computes metrics like volatility rates and coalition blocks, producing `data/processed/*_engineered.csv`.
4. `src/visualization.py` (using `src/visualizations/*`) generates 13 high-resolution chart images in `outputs/figures/`.
5. `app/main.py` and `app/pages/*` run the interactive web application, using `app/utils.py` to filter data dynamically and render interactive charts and automated insights for the user!
