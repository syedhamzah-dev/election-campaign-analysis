Project Overview

🎯 What this project does

This project studies Indian Lok Sabha elections from 2004 to 2024. It reads election data, fixes messy values, creates useful metrics, and turns them into charts and an interactive dashboard that is easy to explore.

  • app/ contains the web dashboard pages people can view in a browser.
  • data/raw/ holds the original election CSV files.
  • data/processed/ holds the cleaned and prepared files used by the app.
  • src/ contains the Python code for cleaning data, creating new insights, and making charts.
  • outputs/figures/ stores the final images that explain the results.

📊 What the figures show

  • fig_01 shows how major alliances changed over time.
  • fig_02 shows which parties turn votes into seats most efficiently.
  • fig_03 and fig_04 explain which states are most volatile and competitive.
  • fig_05 to fig_07 look at reserved seats, extreme margins, and party retention.
  • fig_08 to fig_13 show party performance, turnout, margins, and the difference between EVM and postal votes.

Figure Formulas & Mathematical Audit

Complete mathematical specification, dataset column mapping, aggregation method, and formula documentation for all 13 generated project visualizations.

Featured Focus: Figure 02 — Vote Share vs Seats Won (FPTP Efficiency)

Technical formula breakdown and data science audit for fig_02_vote_seat_conversion:

1. National Vote Share (%)

(Party Votes / Total Valid Votes) × 100

Numerator: Sum of total candidate votes for party in election cycle.
Denominator: Aggregate valid votes cast across all candidates.
Columns: Total Votes, Party, Year.

2. Parliamentary Seats Won

COUNT(Constituencies won by party)

Calculates total parliamentary constituencies where party candidate achieved Rank 1.
Columns: Winner_Party, Seats, Year.

3. FPTP Conversion Efficiency

Seats Won / Vote Share (%)

Evaluates First-Past-The-Post multiplier. Ratios >10 signify high seat conversion per vote %.
Columns: Seat_Conversion_Efficiency.

Contributor Guide

🚀 How to Extend the Repository

1. Adding a New Feature Engineering Metric

Open src/feature_engineering.py, write a vectorized calculation function, and invoke it inside run_feature_engineering_pipeline(). 

def compute_custom_metric(df: pd.DataFrame) -> pd.Series:
    return df["Winner_Votes"] / df["Runner_up_Votes"]

2. Adding a New Visualization Function

Create your plotting routine inside the appropriate submodule under src/visualizations/ (e.g., party.py), export it in src/visualizations/__init__.py, and re-export via src/visualization.py facade.

3. Adding a New Streamlit Page

Create a new file in app/pages/ (e.g., app/pages/6_New_Analysis.py). Streamlit will automatically register it in the sidebar menu!
